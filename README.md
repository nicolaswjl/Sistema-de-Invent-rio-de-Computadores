# 💻 Sistema de Inventário de Computadores

Este projeto consiste em um sistema simples de controle de computadores, desenvolvido em Python, com foco em organização de dados e práticas de lógica de programação aplicadas à área de TI.

---

## 📌 Funcionalidades

- 🖥️ Cadastro de computadores (nome e setor)
- 📋 Listagem de equipamentos cadastrados
- 🔍 Busca por nome ou setor
- ❌ Remoção de computadores

---

## 🧠 Tecnologias utilizadas

- Python

---

## 🎯 Objetivo

O objetivo deste projeto é praticar conceitos fundamentais de programação e simular um sistema utilizado na área de suporte técnico, como:

- Estruturas condicionais
- Laços de repetição
- Listas e dicionários
- Manipulação e busca de dados

---
